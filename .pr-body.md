## New: a standalone PDF & Documents tool for SOLO AI

Turns any content into a polished PDF — fully client-side, no API key or server.

### What's new
- **Standalone PDF tool** — new sidebar view (next to Files/Memory) with a `/pdf` route.
- **Real PDF download** — html2canvas + jsPDF produce an actual `.pdf` file (not a print dialog), so it works reliably online and offline.
- **Any text/markdown** — headings, lists, tables, code blocks, math (KaTeX), links.
- **Images** — "Add image" uploads images from your device and embeds them (multiple supported).
- **Diagrams** — Mermaid diagram blocks render and embed into the PDF, or use the "Add diagram" button.
- **Live preview** — shows exactly what the PDF will look like.
- **Options** — Title, Subtitle, Footer, Page (A4/Letter), Margin, Font (Sans/Serif/Mono), Accent colour.
- **100% client-side, fully free** — no API key, no server, no internet required.
